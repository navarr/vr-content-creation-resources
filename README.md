# VR Content Creation Resources

## Necessary Software

* [OBS Studio](https://obsproject.com/)
* optional, but recommended: [Spout2 Plugin for OBS](https://github.com/Off-World-Live/obs-spout2-plugin)

## Mobile Editing Apps

* [Edits](https://creators.instagram.com/edits/) by Instagram/Facebook/Meta
* [YouTube Create](https://www.youtube.com/creators/create/youtube-create-app/) by Google
* [CapCut](https://www.capcut.com/tools/video-editing-app) by Bytedance (TikTok)

## Desktop Editing Apps

* [Davinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - FREE
* [CapCut Desktop](https://www.capcut.com/) - Free to Start
* [Microsoft ClipChamp](https://clipchamp.com/en/) - Free to Start (not super great)
* [Adobe Premiere](https://www.adobe.com/products/premiere.html) - $$$
